## 0. 你的原话（不改字，作为唯一依据）

> 在弹出窗口右侧添加一个按钮（全功能），页面分成（左右，左侧=80%，是脑图形式，右侧=对话框），
> 用户可以根据左侧的内容进行提问和交流（顶部的模式 =保持不变，用户可以切换：图文、语音、视频模式），
> 本质 = 把当前的会话，移动到右侧。
> 然后左侧内容 = 脑图，【区别在于：脑图 = 一个文件夹，每次对话，默认携带文件夹的绝对路径，
> 用户可以提问也可以修改，文件夹 = 在左侧展开，类似 vscode】，
> 左侧 = 文件夹工作区，中间 = 内容区（点击查看某个文件的内容），逻辑完全相同，
> 用户点击文件 = 自动将这个文件作为（重点参考），同时也自动携带整个项目的绝对路径，
> 可以理解为：新建项目的逻辑，文件夹 = 项目，可以提交 git，等等，所有的对话 = 围绕它进行。
> 中间 = 正文（md 预览，内容编辑，可以实现实时编辑，实时预览）
> 也支持脑图的形式（这是重点，也可以 mermaid 作为脑图，更简单，
> 但必须让用户可选择折叠 mermaid 的代码，只显示脑图），
> 但是区别是：用户必须能在右侧进行对话的方式，编辑脑图的内容，
> 并且任何一次编辑，都必须自动备份历史（参考 git 等方法或其他的，对当前的文件进行历史备份和恢复）。
> 右侧 = 对话窗口。连续对话，临时对话，语音模式等等都行。
> vscode、codex、trae、xiaomi desktop 都是这样的逻辑，只是我的特点是，自己创建这个功能。

## 4. 内容区（左栏右侧）三种看法

### 4.1 点文件 = 重点参考

| # | 需求 | 判据 |
|---|---|---|
| 4.1.1 | 点某个文件 → 打开它的内容 | 内容区换成这个文件 |
| 4.1.2 | **同时自动把它设为「重点参考」** | 文件名旁边出现「重点参考」标记；树上该文件也亮 |
| 4.1.3 | **同时自动携带整个项目的绝对路径** | 上下文条同时显示两条：项目路径 + 重点参考文件路径 |
| 4.1.4 | 换点另一个文件 → 重点参考跟着换 | 同一时刻**只有一个**重点参考 |

`【待你确认】` **能不能同时重点参考多个**（我按：**单选，点谁谁就是重点**）。

### 4.2 正文：md 实时编辑 + 实时预览

| # | 需求 | 判据 |
|---|---|---|
| 4.2.1 | 能看 md 渲染结果（预览） | 标题/加粗/列表/代码块渲染出来 |
| 4.2.2 | 能直接编辑，**实时编辑实时预览** | 左边打字、右边立刻变（同一块区域切「编辑/预览/分栏」也行） |
| 4.2.3 | 保存 = 落盘（进版本历史，见 §5） | 每次改动后历史里多一条 |

### 4.3 脑图（**这是重点**）

| # | 需求 | 判据 |
|---|---|---|
| 4.3.1 | 内容区能以**脑图**形式显示 | 一张真的树状图（节点 + 连线），不是缩进文本 |

| 4.3.3 | **必须能折叠 mermaid 代码、只显示脑图** | 有一个开关/箭头：收起后屏幕上**只剩图**，代码看不见 |
| 4.3.4 | 收起状态记得住 | 下次打开还是你上次留下的状态 |
| 4.3.5 | 图上的节点可以展开/收起分支 | 点分支节点能折叠下面的子树 |

| # | 需求 | 判据 |

| 5.1 | **任何一次编辑**（手改正文、手改脑图、通过对话改）→ **自动**存一版 | 编辑后不用点任何"保存备份"，历史里自动多一条 |

## 7. 与现有软件怎么接（我填的复用清单，你抽查）

| 现有的 | 在本页做什么 | 不新造的理由 |
|---|---|---|
| `CardChatModeBar`（图文/语音/视频那排） | 顶部那排，原样 | 你说"顶部的模式保持不变" |
| `MessageComposerField`（三行输入框） | 右侧对话的输入框 | 三个内容页共用的那一个，粘附件/展开/回车发送都现成 |
| `ComposerAttachment`（粘图/文件/文件夹） | 右侧输入框照常能粘 | 已有，不重复做 |
| 卡片四模式（文本/图文/语音/视频） | 本页对话走同一套路由 | `usesAgentCapability` 那条分界线不变 |
| `AnswerCardView`（回答卡） | 右侧回答的渲染 | 三种主题现成 |
| 临时对话 `TemporaryConversationModel` | 右侧「临时对话」 | 用完即弃、不进会话，语义一致 |

**不做的事**（免得越做越大）：
- 不做多人协作 / 云同步；
- 不接管你已有会话的历史（本页只"把当前会话搬过来"，不复制一份存两处）；
- 不做完整 IDE（补全、调试、终端都不做）。
