## 1. 词

| 词 | 含义 |
|---|---|
| **大循环**（一次任务） | 从**第一次按下快捷键**开始，到 ESC 或"Agent 模式下再按一次快捷键"结束 |
| **实时模式** | 大循环的前半段。**非思考模型** + **临时会话**。回答只上右下角卡片，**不出声** |
| **Agent 模式** | 大循环的后半段。**思考模型** + **正式会话（连续对话）**。回答**显示 + 出声** |
| **临时会话** | 实时模式专用的会话。**进 Agent 模式即作废**（内容已移交） |
| **说话** | 用户开口（麦克风检测到人声） |
| **打断** | **AI 正在播放声音时**用户说话 |
| **追问** | **AI 播放完成之后**用户说话 |
| **提交** | 按下快捷键，把**用户刚说的那句话**发出去 |
| **终止** | 结束整个大循环 |
| **监听窗口** | 麦克风继续开着的那段时间 —— **大循环结束后 60 秒**（§7） |

## 2. 大循环

```
        【开始】第一次按下快捷键
              │
              ▼
    ┌─────────────────────────┐
    │  实时模式（临时会话）     │  说话 → 静音 1 秒自动发 → 卡片（不出声）
    │  追问也在这里循环         │  再说话 → 还是临时会话 → 卡片
    └───────────┬─────────────┘
                │ 按下快捷键 = 强制进 Agent（没有前提）
                │ 移交：全部历史 + 最后一问
                ▼
    ┌─────────────────────────┐
    │  Agent 模式（正式会话）   │  回答 = 显示 + 出声
    │  追问也在这里循环         │  打断 / 追问 → 都还在 Agent 模式
    └───────────┬─────────────┘
                │
      ┌─────────┴─────────┐
      ▼                   ▼
  【结束】ESC        【结束】再按一次快捷键
```

**开始**：第一次按下快捷键。

**结束只有两种**：按 ESC；或**在 Agent 模式下、轮到 AI 时**按下快捷键。

**除这两件事以外，任何按键、任何说话都不结束大循环。**

### 2.1 模式**不会自动退出**

| # | 规矩 |
|---|---|
| 1 | **模式靠快捷键切换，不靠时间**。没有任何"等 N 秒自动回到上一个模式" |
| 2 | **实时模式**：从第一次按下起一直有效，直到你第二次按下（进 Agent）或按 ESC（结束） |
| 3 | **Agent 模式**：从第二次按下起一直有效，直到你按 ESC 或再按一次快捷键（结束）。**关机、重启、隔天回来，都还在 Agent 模式** |
| 4 | 进了 Agent 模式就**回不到实时模式** —— 只有结束这个循环、重新按一次才可以 |

> ⚠️ 它和「监听窗口」是两件事：**模式**是"我在哪个模式"（永久，直到按快捷键）；
> **监听窗口**是"麦克风还开着多久"（§7）。

## 3. 按下快捷键 = 什么？**看"此刻轮到谁"**

| 此刻轮到谁 | 按下快捷键 = |
|---|---|
| **用户**（正在说 / 刚说完） | **发送**（把这句话发出去） |
| **AI**（正在说 / 刚说完） | **结束**（终止大循环） |
| **都不在**（不在大循环里，空闲） | **开始新的大循环** → 实时模式 |

**落到两个模式上**：

| 模式 | 按下 = |
|---|---|
| **实时模式** | **发送 → 强制进 Agent 模式**（**没有前提**）。因为实时模式**不出声**，"AI 正在说"这个状态不存在 → 永远是"轮到用户" → 按下永远是"发送" → 实时模式里的"发送"就是提交给 Agent |
| **Agent 模式** | 用户轮到 → **发送**（仍在 Agent 模式）<br>AI 轮到 → **结束** |

**Agent 模式下用户说完话不按也行** —— **静音 1 秒自动提交**，提交后**仍在 Agent 模式**。

### 3.1 ESC —— 和快捷键相反，**不分场景**

**ESC 是无条件退出。** 用户正在说 / 用户说完 / AI 正在说 / AI 说完 —— **全都是退出**。

（实时模式里同理：ESC = 取消发送 + 取消右下角卡片 + 结束这一轮。）

**一句话**：**ESC = 无条件退出；快捷键 = 看轮到谁**（用户 → 发送，AI → 结束）。

## 4. 说话 = 什么？（打断 / 追问）

**说话本身永远不结束大循环。**

| 什么时候说话 | 叫 | 会发生什么 |
|---|---|---|
| **AI 正在播放声音** | **打断** | ① 立刻停掉正在播的声音 ② **右下角卡片瞬间消失** ③ 麦克风继续收这句话 |
| **AI 播放完成之后** | **追问** | **右下角卡片瞬间消失**，麦克风继续收这句话 |

**为什么说话就要清卡片**：用户说话 = 一个**全新的问题**；卡片上挂的是**上一个答案**，
留着它没有意义（用户看完答案才会去提问）。

**实时模式里只有"追问"，没有"打断"** —— 因为实时模式不出声，不存在"AI 正在播放"这个状态。

## 5. 实时模式（大循环的前半段）

| 项 | 行为 |
|---|---|
| 模型 | **非思考模型**（设置 → Agent →「Pi 模型」里"实时"那一行） |
| 会话 | **临时会话** |
| 说完话 | **静音 1 秒自动发送** |
| 回答去哪 | **结果只出现在一个地方**：实时窗口**没开** → 右下角卡片；实时窗口**开着** → 实时窗口里，右下角**什么都不出**（结果与实时字幕都不出） |
| 出声吗 | **不出声** |
| 追问 | 用户再说话 → **还在这个临时会话里**继续 |
| 追问的节奏 | 同样**静音 1 秒自动发送**，循环 |
| 按 ESC | **取消发送**（这句不发）+ **取消右下角卡片** + 结束这一轮 |
| 按下快捷键 | **强制进 Agent 模式**（§3、§6） |
| 什么时候离开 | **只有**按下快捷键或 ESC。**没有自动退出**（§2.1） |

## 6. 进 Agent 模式那一刻（**移交**）

### 6.1 移交什么

两块，**顺序固定**：

1. **全部历史** —— 实时模式下的**所有**聊天记录（用户说的 + 实时模式回的），**一条不少**。
2. **用户最后那一句问题** —— 单独提出来，作为要 AI 完成的**目标**。

**为什么要全部历史**：用户可能追问三轮、五轮、十轮，这些内容他**以后可能要用**
（整理成笔记、保存完整记录），所以不能只给一部分。

⚠️ **上下文压缩也要考虑**：临时会话有会话记录、上下文管理、**上下文压缩**。
**如果上下文过爆或曾经触发过压缩，就要把完整原文（会话文件）给 AI** ——
**不能拿压缩过的摘要去移交。**

### 6.2 用什么格式写（XML 标签）

**两个标签，各自独立，谁也不包谁。**

```xml
<history>
[用户] 帮我看看这篇文章
[助手] 这篇文章讲的是……
[用户] 再短一点
[助手] 讲的是……
[用户] 把这些整理到笔记里
[助手] 好的，整理成这样的三条……（← 保留，它属于历史）
</history>

<goal>把这些整理到笔记里</goal>
```

| 标签（名字） | 里面放什么 |
|---|---|
| **`<history>`** | **全部历史 —— 包括最后那一问、以及它的回复**。一条不少 |
| **`<goal>`** | **只有用户最后那一句问题**，**不带它的回复** |

**为什么 `<goal>` 里不要回复**：那个标签是"**要它去做的事**"，不是"已经做过的事"。
把回复塞进去，它就可能以为已经做完了。

**还要告诉 AI 一句**：**以最后一句话为标准，来完成用户的要求或任务** ——
用户最后那句很可能是一个**执行指令**（例：连续追问十轮之后说"把这些整理到笔记里"）。

### 6.3 同时发生的三件事

| # | 事情 |
|---|---|
| 1 | **右下角卡片消失**（那张是实时模式的答案，已经不是重点） |
| 2 | **实时模式的代码不再执行** —— 临时会话那条链整个停掉 |
| 3 | **临时会话的内容全部清空**（已以历史形式进 Agent 会话） |

**但麦克风不能停** —— 继续开着，因为接下来是 Agent 模式。
（**麦克风**开不开 与 **声音引擎**热不热 是两件事，见 §7。）

## 7. 麦克风 / 引擎开多久

**引擎热着的目的**：让它**能识别用户的声音、能识别打断**。

| # | 规矩 |
|---|---|
| 1 | **麦克风从"按下快捷键进实时模式"那一刻就开着** |
| 2 | **整个大循环期间一直开着** —— 循环内部**不倒计时**（会话在继续，它就在听） |
| 3 | **大循环结束后，再热 60 秒**（这 60 秒里说话**不会被处理**，纯粹让引擎别凉） |
| 4 | 那 60 秒的**唯一目的**：用户**第二次发起循环**时引擎是热的 → **立刻**能听、能打断，不用等启动 |
| 5 | 数字 = **60 秒** |

**声音引擎**（另一个东西）：开口快不快 —— 继续热着 **3 分钟**
（设置 → 听 →「引擎保持时间」，可调 1/3/5 分钟 / 永久）。

## 8. Agent 模式（大循环的后半段）

| 项 | 行为 |
|---|---|
| 模型 | **思考模型**（设置里"执行"那一行） |
| 会话 | **正式会话 = 连续对话** |
| 回答 | **右下角卡片显示 + 出声播放** |
| 追问 | 用户说话 → **还在 Agent 模式下继续** |
| 追问显示在哪 | **不需要在临时会话里显示**（临时会话已作废） |
| 说完话 | **静音 1 秒自动提交**，提交后**仍在 Agent 模式** |
| 按 ESC | **终止**（结束大循环） |
| 再按一次快捷键 | 轮到 AI → **终止**；轮到用户 → **发送** |
| 能回实时模式吗 | **不能**（§2.1） |
| 什么时候离开 | **只有** ESC 或再按一次快捷键。**没有自动退出**（§2.1） |

## 9. 一句话总表

| 你做的事 | 结果 |
|---|---|
| **第一次**按快捷键 | 开始大循环 → **实时模式** |
| 说话，停 1 秒 | 自动发送 → 卡片（不出声） |
| 又说话 | 卡片**立刻消失** → 还在实时模式（临时会话）里追问 |
| **再按一次**快捷键（实时模式里） | **强制进 Agent 模式**（移交全部历史 + 最后一问） |
| 说话，停 1 秒（Agent 模式里） | 自动提交 → 卡片 + **出声** |
| AI 出声时你说话 | **打断**（停声 + 卡片消失）→ 说完 1 秒自动提交 |
| AI 说完后你说话 | **追问**（卡片消失）→ 说完 1 秒自动提交 |
| 结果显示在哪 | **只在一个地方**：窗口关 = 右下角卡片；窗口开 = 窗口里（右下角不出） |
| **AI 说话时**按快捷键 | **结束大循环** |
| **你说完话**按快捷键 | **发送** |
| 按 **ESC**（任何状态） | **无条件结束大循环** |
| 结束后 60 秒内再按快捷键 | 引擎还是热的 → **立刻**能听 |
