## 8. 卡片用哪个「聊天模式」——**按来源分叉**（2026-09-28 你口述）

| 这一轮从哪来 | 用哪个模式 |
|---|---|
| **按下说话键**（每一大轮的第一次按下 = 进 agent 模式） | 一律切到 **图文** |
| **看板 ⌥⏎ 执行**（= 进入 Agent 模式） | 一律切到 **图文** |
| 在窗口的输入框里**打字提问** | **不动**，用模式条上选的那个 |

你的一句话把规则说全了：「用户点击快捷键（最开始，和进入 Agent 模式的时候），必须自动切换成
（图文模式），之前好像是根据窗口中点击的模式进行的，这是不行的。必须是【图文模式】，
**但是窗口中对话的时候，根据窗口中选择的模式继续就行**」。

三个实现上的分寸（写在这里免得下次被改回去）：

- **只在真的不一样时才写**。`setMode` 每次都落一次 `AppSettings.json` —— 按一次键写一次盘，
  那是越权。⚠️ **2026-09-29 更新**：它原来还顺手把「文本模式默认静音」写进 `voiceReplyMuted`，
  而**文本模式已经删掉**，那一行随之删除 —— 所以现在**切模式不会再动你的静音设置**
  （你手动设的静音从此不会被切模式重置）。
- **提交那一刻还要再切一次**，不能只在按下时切：模式是按卡片存在磁盘上的，而一轮实时对话
  中间用户完全可能去点了模式条（点模式条不算"窗口中对话"）。
- **判据在类型上兜底**：提交那个函数多了一个**没有默认值**的 `comesFromTalkShortcut`
  参数 —— 四条提交路径（确认轻点 / 松键 / 打字 / 连续追问）里三条传 `true`、打字那条传
  `false`。没有默认值 = 将来加第五条路径时**编译器**会拦住"忘了表态"的人，
  不会让它悄悄跟着窗口走。
- **只认主循环那张卡片**：这条快捷键送出去的问题只进主循环；Claude Code 卡片是另一条路
  （`AgentSessionManager.sendTurn`），归它的模式条管。

## 9. 图文模式那一通「通话」（2026-09-28 你口述）

它是**一条独立的通话**（`TextCallController`）：说一句话 = 在那张卡片的输入框里打一行字并回车，
回答走这张卡片原本的管线。刘海借语音 / 视频那条通话同一个相位（`Call` + 右侧那颗红电话），
**三种模式共用同一个挂断**。

> ⚠️ **2026-09-29 这一条的适用面变了**：原来写的是「文本 / 图文模式」，而**文本模式已删** ——
> 这通电话现在只剩**图文模式**这一个入口（前提是那张卡片选的是图文）。
> 下面提到的「文本模式默认静音」那条规矩也随文本模式一起删了（见 §8 末的更新）。
> **页头那颗通话按钮的位置也变了**：三个模式的通话键统一搬到**页头右侧、角色左边**
> （你 2026-09-29：「将【图文、音频、视频】所有模式，通话按钮，全部放在（导航栏的：右侧）」）。

你这次定的两条：

| # | 规则 | 你原话里的关键部分 |
|---|---|---|
| 1 | **点挂断，正在播放的声音必须立刻停** | 「点击挂断，正在播放的声音也必须停止」 |
| 2 | **接通后后台自动发一句提示词，让 AI 先说「你好」，且不进对话界面** | 「后台自动发送提示词，让 AI 首先说话……不要显示在（窗口的对话界面中），目的 = 让用户知道，通话已经连接」 |

三条实现上的分寸（写在这里免得下次被改回去）：

- **挂断走的是"停止"这条路，不是"关麦"这条路**。只关麦克风的话，正在合成 / 正在念的那一段
  会继续念到底 —— 实测（2026-09-28，真机）挂断之后日志里 `📞 文本通话结束` 紧接着
  `🔊 Bailian TTS: playing segment 4 / segment 5` ✓ 声音还在说。所以文本通话的挂断调
  `interruptActiveResponse()`（停播报 + 取消这一轮），它里面"任务在跑时只停播报、不杀任务"
  那条既有规矩原样保留 —— **挂断不该比 ESC 更狠**。
- **招呼读的是语音聊天那一个设置**（设置 → 语音聊天 → 连接：「连接后让 AI 先打招呼」+
  「第一句说什么」），不另配一份 —— 两条通话是同一件事：**"接通了没有"的判据是听见它出声**。
- **招呼那一轮必须出声，哪怕当前模式是静音**。「文本模式默认静音」（2026-09-26 你定的）
  是按定义写进 `voiceReplyMuted` 的，而招呼的全部目的就是被听见 —— 实测第一版在图文模式下
  正常、文本模式下一声没有（你报的「文本模式，AI 没有首先说话（你好），图文 = 实现了」）。
  现在只有**我们自己那一句探针**绕过静音门禁，**回答仍旧按文本模式的规矩只显示文字**。
  ⚠️ 其中「文本模式默认静音」那条已在 2026-09-29 随文本模式一起删除（见 §8 末）。
