# 学习 · 用一道题覆盖全部知识点

> 这是一个**独立模块**的起点：把某个领域的全部知识点映射进一道分阶段的大题里。
> 第一版领域 = **小学数学**，7 关（7 个难度阶段），上一关的能量数是下一关的输入。
> 未来扩展：物理 / 化学 / 历史 / AI / 任意一本书的知识体系；与 AI 对话结合，形成「系统学习 / 专家学习」模块。

## 原型怎么跑

```bash
cd /Users/mjm/Documents/SuperAgent/Wanna/学习
python3 -m http.server 8642 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8642/
```

原型包含：七关闯关作答（自动判分）、知识点地图（左栏）、**全部对照关系**（右栏抽屉，双向高亮）、
诊断报告（错题 → 薄弱知识点）、演示模式（一键解锁看答案）、进度本地保存与导出。

## 设计原则（三条，改动前先读）

1. **先清单，后映射**：知识点清单是底稿；题必须覆盖清单上每一个点（双向、可核对）。
2. **链式解锁**：第 N 关的能量数 = 第 N+1 关的输入；不按顺序走不下去。
3. **提示给知识，不给答案**：点「提示」得到的是对应知识点的讲解，先补知识再解题。
