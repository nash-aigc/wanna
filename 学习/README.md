# 学习 · 用一道题覆盖全部知识点

> 这是一个**独立模块**的起点：把某个领域的全部知识点糅合进**一道题**里。
> 第一版领域 = **小学数学（92 个知识点）**；**第 1~7 道题 = 7 个难度**（同一副骨架：
> 知识点完全相同，难度靠问法变式 + 题内连锁加深 —— 不是七批题）。
> 未来扩展：物理 / 化学 / 历史 / AI / 任意一本书的知识体系；与 AI 对话结合，形成「系统学习 / 专家学习」模块。

> ⚠️ **2026-10-02 澄清（最重要）**：对学生**永远只有一道题** —— 一个故事、一张连续任务卷，
> 从第 (1) 步做到最后。第一版做成的「7 关 × 每关一串题」是错的，已重构。
> 详见 [`01-需求完整记录.md`](01-需求完整记录.md) §一·五。

## 原型怎么跑

```bash
cd /Users/mjm/Documents/SuperAgent/Wanna/学习
python3 -m http.server 8642 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8642/
```

原型包含：**一道题**的连续任务卷作答（自动判分）、顶栏切换七种难度、知识点地图（左栏）、
**全部对照关系**（右栏抽屉，双向高亮）、诊断报告（跨难度）、演示模式（看答案）、
进度本地保存与导出、最后一步答对点亮灯塔。

## 设计原则（三条，改动前先读）

1. **只有一道题**：任何让页面变成「题的列表 / 关卡墙」的改动都违背需求。
2. **七道题同一副骨架**：改知识点/步骤要改 `data-questions.js` 的一份骨架，七道题同时生效；
   差异只允许来自「问法变式 + 连锁密度」，数值不放大。
3. **提示给知识，不给答案**；题、知识点、映射三份产物由 `make-docs.js` 同源生成。
