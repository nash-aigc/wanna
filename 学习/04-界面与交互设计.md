# 04 · 界面与交互设计 —— 「学习」页面（一道题形态）

> 2026-10-02 按「**只有一道题**」的澄清重写（见 `01-需求完整记录.md` §一·五）。
> 本文是设计说明；可点的实现在同目录 `index.html`（原型即本设计的实现）。
> ⚠️ 先忽略对话框；页面内所有辅助窗口（对照抽屉、未来 AI 对话窗）必须**可隐藏**。

---

## 一、设计目标（四条，全部来自需求）

1. **打开就是一道题** —— 中间永远是一张连续任务卷（一个故事 + 第 (1) 步做到最后），不是题的列表、不是关卡墙。
2. **一眼看到全部知识点** —— 左栏常驻 92 个知识点地图，不因做题进度藏起来。
3. **作答即诊断** —— 每步判分；错 → 标到知识点 → 讲解 → 回来重做，闭环不离开这一页。
4. **难度不制造痛苦** —— 顶栏切换第 1~7 道题（同一张卷的七种难度），**没有关卡锁**，随时可看、可做、可回。

---

## 二、整体布局（顶栏 + 三栏）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶栏：🗼数学岛·点亮灯塔   ①入门②熟悉③进阶④熟练⑤挑战⑥高手⑦巅峰（难度切换）│
│       掌握 37/92 · 第 2/7 道        [全部对照关系][诊断][演示][导出][重置]  │
├──────────────┬─────────────────────────────────────┬─────────────────────┤
│ 左栏 知识地图  │ 中栏 · 一道题（当前难度的题卷）        │ 右栏 · 对照关系抽屉   │
│ (260px,可收起)│ ┌ 第 2 道题 · 难度2/7（熟悉） [→下一题]┐│ (360px,可隐藏)       │
│              │ │ 故事段落……（这是一道题，从(1)做到底）  ││                     │
│ ▸ 一年级 17   │ │ (1) 背包 8 瓶水 5 块面包… [ ][检查]  ││ 模式：[按步骤][按知识点]│
│   ● 比多少 ✓ │ │      提示：凑十法……        换法标签    ││                     │
│   ● 钟表  ✗  │ │ (2) …        →取 (12) 的结果（连锁chip）│ │ (1) 题干片段 → 知识点 │
│ …            │ │ …                                   ││                     │
│ ▸ 二年级 13   │ │ (101) 🗼灯塔密码：全部结果之和 [ ]    ││ 点任一侧另一侧高亮     │
└──────────────┴─────────────────────────────────────┴─────────────────────┘
```

| 区域 | 职责 | 关键交互 |
|---|---|---|
| **顶栏 · 难度切换** | 7 个点 = 第 1~7 道题（不是关卡）；点亮态打 ✓ | 点击直接切换题目；当前题高亮；**无锁** |
| **左栏 · 知识地图** | 92 点按年级陈列，绿=掌握 / 琥珀=待巩固 / 灰=未作答 | 点知识点 → 讲解弹卡 + 跳到题卷对应步；可折叠 |
| **中栏 · 一道题** | **唯一的作答区**：故事 → 连续编号步骤 (1)…(N) → 最后一步点亮 | 每步：作答 + 检查 + 提示；连锁步带「→取 (x) 的结果」跳转 chip |
| **右栏 · 对照抽屉** | 当前题的 步骤 ↔ 知识点 双向映射（全部对照关系的落点） | 按步骤/按知识点两种排法；双向高亮跳转；可隐藏 |

## 三、七个难度 = 七道题（同一骨架）

| 难度 | 名称 | 与第 1 道题的差异 |
|---|---|---|
| 1 | 入门 | 全直问；只有末段连锁（总能量 → 密码） |
| 2~3 | 熟悉 / 进阶 | 两~四成步骤「换法」（逆向问法，带**换法**标签）；出现中段连锁汇聚 |
| 4~5 | 熟练 / 挑战 | 过半~七成换法；连锁每 23~12 步一个，且首尾相接 |
| 6~7 | 高手 / 巅峰 | 几乎全部换法；连锁最密（每 11~12 步），末段连锁再接上前面所有连锁 |

- **步数** 99 → 107（多出来的都是连锁汇聚步，不是新知识点）。
- **知识点恒为 92**，每道题独立覆盖；做任意一道完整 = 全部知识点被检测。
- 切换题目不丢作答（每道题独立存档）；掌握度与诊断**跨七道题聚合**。

## 四、核心交互（五个流程）

### 4.1 做题流（主流程）

```
顶栏选一道题（默认第 1 道）→ 读故事 → 从 (1) 顺次作答 [检查]
  ├─ 对 ✓ → 步骤绿、对应知识点点亮
  ├─ 错 ✗ → 知识点标待巩固 + 展开「考察哪个知识点」+（连锁步）指出依赖的哪一步没对
  └─ 连锁步 → 可点「→取 (x) 的结果」跳回引用步核对
最后一步（灯塔密码）答对 → 点亮动画 → 提示「挑战下一道」
```

- **无关卡锁**：七道题随时可切；点亮只是成就标记。
- 回车 = 检查当前输入框。

### 4.2 提示流（提示给知识，不给答案）

每步「提示」→ 展开该步知识点的**名称 + 一句话讲解**；不出数字、不给答案。

### 4.3 诊断流（作答即检测）

- 答错 → 其知识点标 ✗ 待巩固（左栏变琥珀）；改对 → 恢复绿。
- 聚合规则（跨七道题）：**任一步答错 → 待巩固；任一步答对且无错 → 已掌握**。
- 「诊断报告」按年级列出薄弱点 + 讲解 + **跳到出错的那一步**（若在别的难度，自动切过去）。

### 4.4 对照流（全部对照关系）

顶栏「全部对照关系」→ 右栏抽屉（可隐藏）：按步骤 / 按知识点两种排法；
点知识点 → 题卷里所有相关步骤描边高亮并滚动到位；点步骤 → 左栏 chip 与抽屉行同步高亮。

### 4.5 记录与导出

- 作答即时写 localStorage（按 `难度:步骤` 分开存，刷新不丢）；
- 「导出记录」JSON：七道题全部作答 + 判分 + 薄弱知识点；
- 「演示模式」：每步出「看答案」；「重置」清空（二次确认）。

## 八、设计决策记录

| 决策 | 理由（对应需求） |
|---|---|
| 中栏只有**一道题**，顶栏切换难度 | 「只有一道题……很多道题会有一种痛苦」——列表/关卡墙即痛苦 |
| 难度差异 = 问法变式 + 连锁密度，**数值不放大** | 「知识点完全相同，利用方式/难度增加」；数值放大 = 知识点漂移 |
| **无关卡锁** | 不制造被迫感；点亮与下一道按钮只做引导 |
| 连锁收在题内（连锁汇聚→总能量→密码） | 「阶段结果作为下一阶段输入」在一道题内部成立 |
| 知识点状态跨七道题聚合 | 一道题测全 92 点；在更难的题里答错仍要暴露薄弱 |
| 题、知识点、映射同源生成 | 手写多份必然漂移（本仓库既有教训） |
