## 一、这个东西是什么（一句话）

**把某个领域（先从小学数学开始）的全部知识点，糅合进一道题里；**
**解这道题就必须用到每一个知识点，从而用一道题代替题海战术，完成「学习 + 检测 + 兴趣」三件事。**

---

## 一·五、⚠️ 2026-10-02 重要澄清：只有一道题（覆盖此前「七关」的错误理解）

> **用户原话**：「你现在整个的逻辑不对。你现在是出了很多道题，每一道题对应一个知识点。**我要的是一道题，一道题包含所有的知识点，把这些知识点糅合在一道题上。只有一道题。**……如果升级关卡，那就是第二道题，而第二道题跟这道题的**知识点完全相同**，只不过对知识点的**利用方式、使用方式或者难度**可能会增加一点。类似于简单的题和复杂的题，里面的知识点是一样的，但还是一道题。……如果一个学生遇到很多道题，他会有一种痛苦……**你现在完整地呈现了这个痛苦，我不希望这个痛苦出现。**」

据此，形态定为（本条优先于下文一切与之冲突的描述）：

| # | 规则 |
|---|---|
| 1 | **对学生永远只有「一道题」**：一个故事、一张连续任务卷，第 (1) 步一路做到最后一步；不是「关卡列表」、不是一堆独立小题 |
| 2 | **7 = 7 个难度 = 第 1~7 道题**（不是七关）。每道题的知识点与骨架**完全相同**，差异只有：① 问法变式（直问 → 逆向/绕弯，越难越多）② 题内连锁密度（越难链越深：上一步结果喂下一步） |
| 3 | **数值不随难度放大** —— 难度不能靠把数字变大实现，否则知识点会漂（一年级的「20 以内加法」放到巅峰还是它） |
| 4 | 七道题独立作答、独立记录；一道题最后一步答对 = 点亮，提示挑战下一道，**不做强制锁**（不制造痛苦） |
| 5 | 「阶段结果作为下一阶段输入」（§2.2）收进**一道题内部的步骤连锁**实现，不是题与题之间的锁 |

**为什么单独立一节**：第一版实现成了「7 关 × 每关一串题」的闯关列表，完整呈现了题海的形式感 —— 正是需求要消灭的东西。后续改这个模块，先读本节。

## 二、需求原文要点（按用户口述整理，保留关键原话）

### 2.1 起点：一道非常复杂的数学题

- 设计一道**非常复杂、非常有意思**的数学题，特点是**包含所有小学数学知识**。
- 「可以理解为：一道数学题里包含所有小学数学相关的知识点。」

### 2.2 分阶段（闯关）结构

- 题目分阶段：**第一阶段的解决结果，作为第二阶段的输入**；第二阶段的结果再作为第三阶段的输入……
- 用户最初的类比：**一个年级 = 一个阶段**，小学一~六年级的知识各为一个阶段，上一阶段的最终答案是下一阶段的参数。
- 「整体上不一定有阶段的概念，但如果按照阶段来设计、学习、解答，可能会更加顺畅；不按阶段解决，可能很难实现。」
- **难度档数**：最初说十一道题对应十一种难度，随后自己调整——「我觉得十一个难度有点大，调整一下，**改成七个**」。
  → 本项目按 **7 道题 = 7 个难度** 设计（2026-10-02 澄清：见 §一·五，「关卡」不是一批新题，是同一道题的更难版本）。

### 2.3 放进现实故事 / 场景

- 「这道题可以放在现实中的一个故事或场景里，并且包含所有知识点。」

### 2.4 目的（两个，用户明确列出）

> 「目的有两件事：
> 1. 让一个人能够看到整个小学数学所有的知识点。
> 2. 让他在解答或参考提示的时候，知道这道题里的哪一句话、哪一个问题对应小学中的哪一个知识点——它们之间存在**非常强的对照关系**。」

- 对照关系可以点「**全部对照关系**」查看。
- 对照关系同时是**提示/暗示**：想解决某一步，先把对应的那个知识点解决掉，解决完就能解出这道题的其中一个步骤。

### 2.5 对比题海战术（为什么这样做）

- 现有检测方式：出很多题、刷很多题、看各种类型——「**题海战术，或者说是一个完全不可能学完的战术**」。
- 「刷一百道题，可能也没有办法包含所有知识点，这些题是老师设计的，或者只是检测某一个知识点。」
- 「但如果**先把所有知识点罗列出来**，再去把这道题里的内容对应起来……」→ 所以必须先有完整知识点清单，再做映射。
- 「不需要让他学写、解决很多题……**就是完整的题，对应几个难度**。」

### 2.6 价值一：诊断（知道哪个知识点欠缺）

- 学生把答案交上来时，**根据他的错误判断出他哪个知识点不了解**。
- 「让学生知道自己哪个知识点欠缺」——不需要考试时做很多题，只需要做这一道题。
- 错误报告 / 问卷反过来用：**根据错的问题，反向提供、介绍那个知识点**，让他理解它。

### 2.7 价值二：兴趣与认知（知道每个知识点都有价值）

- 「通过闯关游戏的方式吸引学生的兴趣。」
- 「让孩子知道怎么看待这些知识点，让他们真正认识到**这个知识点是有价值的**。」
- 「未来……就能知道：如果他想解决某一道问题，就必须知道之前学过的所有知识，无论是数学、物理、化学，**它们都非常有价值，而不是说某一个知识点、某一道题没有用、考试不考**。」
- **明确不考虑考试**：「咱们不考虑考试的问题」，考虑的是复习、检测、认识知识价值。

### 2.8 学习目标（反向使用）

- 学生可以**反复复习或检测**自己哪些知识点不了解。
- 「要想解决这道题，就需要学习所有数学知识」——题是目标，知识点是过关所需的钥匙。

## 三、核心机制（把口述变成可实现的规则）

| 机制 | 规则 |
|---|---|
| **知识点清单** | 先罗列某领域的**全部**知识点（小学数学 = 92 条，按年级分组），这是地图的底稿 |
| **题目 = 一道题** | 一个现实故事 + 一张连续任务卷；**每个知识点是这道题里的一步**，不是一道独立小题 |
| **难度 = 换一道题** | 第 1~7 道题骨架相同；难度靠**问法变式 + 连锁加深**提升（见 §一·五） |
| **题内连锁** | 一道题内部：前一步的结果成为后一步的输入（连锁汇聚 → 总能量 → 灯塔密码），越难链越密 |
| **强映射** | 题中每一步 → 标注考察的知识点编号；每个知识点 → 至少对应一步（双向、全覆盖） |
| **全部对照关系** | 一个可点击的视图：步骤与知识点互相高亮、互相跳转 |
| **提示 = 知识点** | 「提示」按钮不直接给答案，而是给出**对应知识点的名称与讲解**（先补知识，再解题） |
| **提交判错** | 每步判分；错 → 把它对应的知识点标记为「待巩固」 |
| **诊断报告** | 根据错误聚合出「你薄弱的知识点清单」，按年级/领域分组，可点回原步重做 |
| **记录保存** | 七道题的作答、判分、点亮进度都保存下来（本地持久化），可导出 |
| **点亮** | 一道题最后一步（灯塔密码）答对 = 该道题点亮 = 该道题把 92 个知识点全部走完 |

## 四、价值主张（为什么值得做成一个模块）

1. **一份清单**：打开就能看到某领域**全部**知识点（不再迷茫「我该学什么方向」）。
2. **一道题**：不用刷一百道题；一道题把所有点串起来，每个点都能被检测到。
3. **一次作答**：交上答案就得到诊断——哪个点会、哪个点不会，精确到知识点。
4. **反向教学**：错误直接链接到该知识点的讲解，缺什么补什么。
5. **兴趣**：故事 + 题内连锁 + 最终点亮，一道题从头做到尾有成就感，而不是刷完一批题。
6. **认知升级**：孩子亲身体验「少了这个知识点这一步就过不去」，从而相信**每个知识点都有价值**。

## 五、未来发展方向（用户口述，完整保留）

### 5.1 题目形态

- 未来题不需要很多：**一共若干道，对应若干个难度档**（本版：七道题七个难度；曾提过 11 档后主动降为 7）。
- 不要「第一道题、第二道题、填空题、简答题」这种题型罗列形式，就是**完整的、分难度的几道大题**。
- 题的难度可以**不断跃迁、不断变化**。

### 5.2 跨学科扩展

- 先做数学；未来扩展到**物理、化学**，再到**语文、历史、政治、地理**。
- 「让孩子不会觉得这些知识没有意义」「联动到语文、物理、化学、历史、政治、地理」。
- 初中、高中、大学：**同一套方法论逐级上探**。

### 5.3 与 AI 对话结合

- 「我可以跟一个孩子对话，判断他是不是了解整个历史知识、所有高中/初中历史……他在跟 AI 对话的时候就能学到所有知识，也能解决自己所有的问题。」
- **过程中所有记录全部保存下来**。
- 对话本身可以是检测的一部分：AI 提问 → 学生回答 → AI 判定知识点掌握情况。

### 5.4 通用化：任何领域都能「一题复现」

> 未来他可能突然想学 AI：「我想学习 AI，我想全面了解 AI」，但现在不知道从哪个方向走。

- 通过一道实战题，看到自己将来会遇到的**场景集合**；场景里的每个问题都对应一个 AI 知识/功能/模块/工具。
- **把行业的一本书（100 或 1000 个知识点）融合进一道题**，通过这道题反向知道自己该学哪个知识点。
- 「让每个知识点都有价值，让每个知识点都能在题中有一个对应的映射关系。」

### 5.5 产品化：打包成独立模块

- 「未来我可能会在这个项目里面打包出专门的一个模块：**强制学习 / AI 学习 / 强制复盘 / 系统学习**的方法论。」
- 两种模式：
  - **系统学习**：给它一道题，全面了解整个系统（全部知识点）；
  - **专家学习**：针对自己行业的知识体系（一本书、一个知识库）做同样的事。
- 在本软件导航栏里新增一个页面（名字候选：**系统学 / 强制学习 / 学习**）：
  - 是一个全新的页面，包含一个**独立窗口**；
  - **对话窗口完整保留**（图文、音频、视频、输入框、输入框上方的控件全部不变），未来加入 AI 学习对话；
  - 页面里的**内容、映射关系可以调整，这个窗口可以隐藏**。

### 5.6 本阶段的边界（用户明确划的）

- **当前重点不是对话框放哪里**——先忽略对话框。
- 当前重点：**整个软件界面怎么设计、交互怎么设计** → 思考清楚 → **实现出来** → 用户再调整。
